# SOS Orelha — Landing Page

Next.js (App Router) + Tailwind CSS v4.

## Rodar
```bash
npm install
npm run dev
```
Abra http://localhost:3000

## Trocar a imagem do hero
1. Coloque a imagem em `public/images/orelha.jpg`
2. Em `components/Hero.tsx`, altere `HERO_IMAGE` para `"/images/orelha.jpg"`

## Cores
Definidas em `app/globals.css` (`--color-brand` = vermelho).
